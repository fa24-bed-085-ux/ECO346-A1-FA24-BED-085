# ECO346-A1-FA24-BED-085
**Registration Number:** FA24-BED-085

**Variant:** 5 — KP Urban

## Project Overview
This project analyzes annual earnings by age using PSLM data. The analysis includes earnings distribution, weighted median and percentiles, age-band weighted mean earnings, and data visualization using R and Python.

## Repository Structure
- `data/` — Household and person CSV datasets
- `scripts/` — R and Python analysis scripts
- `figures/` — SVG graphs generated by the scripts
- `slides/` — Final presentation

## Tools Used
- R
- Python
- RStudio
- Google Colab
## Sample
The analysis focuses on urban earners in Khyber Pakhtunkhwa, aged 15–64, with positive annual earnings.
